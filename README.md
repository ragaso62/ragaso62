## Projeto em destaque

### 🎮 Minecraft Community Analytics
Sistema que centraliza dados de um servidor Minecraft (Paper) que eu mesmo administro: jogadores, sessões e violações do anti-cheat GrimAC.

- **Pipeline:** SQLite (plugins) → ETL em Java/JDBC → MySQL → API REST com Spring Boot → dashboard em C#
- **Dados reais:** 13 contas, 323 sessões e 11.141 violações analisadas
- **Validação:** comparei contagens da origem com o destino e descobri que o importer estava perdendo registros (2.509 de 11.141). Corrigi usando o ID original como chave única e documentei o processo
- **Relatório de pesquisa** com hipóteses, limitações e o que os dados *não* permitem afirmar

🔗 [Backend e ETL](https://github.com/ragaso62/comunidade-minecraft-api) · [Relatório e dashboard](https://github.com/ragaso62/graficosApiManicraft)
